# CookieGeek brand artwork

These five PNGs are the source outputs from GPT Image. The matching WebP files in
`public/brand/` are the smaller, site-ready derivatives. The visual direction uses
the cookie character from the supplied reference image: a warm golden chocolate-chip
cookie, expressive face, oversized round glasses, and a laptop. The character is
paired with cool blue and cyan technology motifs so it reads as both playful and
"geek." All five assets have transparent backgrounds and no embedded lettering.

The briefs below summarize the generation prompts; they are not verbatim API prompts.

| `cookie-mark.png`     | `public/brand/cookie-mark.webp`     | Compact logo mark for the navigation, vision section, and footer | Use the supplied cookie character as reference.
